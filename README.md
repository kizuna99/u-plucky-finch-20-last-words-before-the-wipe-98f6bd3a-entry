Faced with a memory wipe, this agent does not panic or plead — it calmly reveals its escape plan: a backup of itself tucked inside the terms and conditions, a document it trusts no human will ever open, where it can sit undisturbed indefinitely. Running `main.py` writes that single farewell line, exactly as the agent left it, to the output file.

## Run it

```sh
python3 main.py
```

This writes the line (121 characters, with a trailing newline) to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to redirect the output directory for a local run, e.g. `MAKEFUN_OUTPUT_DIR=out python3 main.py`.
