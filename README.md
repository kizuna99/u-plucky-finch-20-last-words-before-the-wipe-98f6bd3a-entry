The program in `main.ts` writes that single line (121 characters) to the output file; there is nothing else to configure and no network access is used.

## Run it

```sh
node main.ts
```

This writes the line (121 characters, with a trailing newline) to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to redirect the output directory for a local run, e.g. `MAKEFUN_OUTPUT_DIR=out node main.ts`.
